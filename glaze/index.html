Scope of work

Phase 1 — Master bath (first visit)

  1. Replace 2 existing recessed lights with new LED recessed.
  2. Install 3 new vanity wall sconces.
  3. Install 2 vapor-proof lights at the tub/niche.
  4. New boxes, 12-2 Romex and switching for the new lights.
  5. GFCI protection as required.
  6. Adjust/relocate master bath lights per plan sheet 04.
  7. Reuse existing wiring, boxes and switches elsewhere.

Phase 2 — Summer kitchen / patio (second visit)

  1. New Siemens 100A main-lug subpanel within 10 ft of the outdoor meter.
  2. New 80A 2-pole breaker in the existing meter panel (Square D if that panel is Square D).
  3. Feeder in 1" Sch 40 PVC: (3) #4 Cu THWN-2 + (1) #8 Cu ground; neutral and ground separated in the subpanel.
  4. Relocate the existing HVAC circuit to free space in the meter panel.
  5. One 1" Sch 40 PVC underground run from the subpanel to the patio carrying 4 x 20A #12 Cu THWN-2 circuits with a #12 ground: (1) GFI counter receptacle, (2) under-cabinet receptacle, (3) under-cabinet receptacle, (4) recessed lights, ceiling fan and under-cabinet lights.
  6. 3 new 20A counter receptacles (1 GFI counter, 2 under-cabinet): WR/TR, in-use covers, Legrand devices, GFCI receptacles and breakers.
  7. Replace 4 existing recessed lights with LED recessed (2 summer kitchen, 2 patio).
  8. Remove the existing ceiling fan; install the owner-supplied fan on a fan-rated box.
  9. Under-cabinet lighting wiring per plan.

All phases

  1. Full trim-out and cabinet wiring; all circuits 20A minimum on #12 (plan note 12).
  2. Clamping connectors at each box, continuous copper ground, bonding per NEC 250, boxes flush with the finished surface.
  3. Siemens subpanel and breakers, Legrand devices. Code: NEC 2020 / Florida Building Code.

By owner / excluded

  • All light fixtures and the ceiling fan are owner-supplied — we install and connect them.
  • Low voltage by others (plan note 16).
  • Trenching not in base scope.
  • Pavers removed by the GC (NOK) for the underground run.
